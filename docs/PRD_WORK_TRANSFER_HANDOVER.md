# CATV 업무관리 — 업무이관 정책

## 등록

- 등록 권한은 관리자, 공무, 팀장에게 있다.
- 점검요청일은 한국시간 오늘이 기본값이며 변경할 수 있다.
- 지역은 평택안성, 용인, 수원, 오산화성만 사용한다. 팀장은 담당 지역으로 고정한다.
- 고객주소는 선택값이며 공란 등록과 수정이 가능하다.
- 일반·연속 등록은 JPG, PNG, WEBP 사진을 1~3장 첨부한다. 장당 한도는 10MB다.
- 연속등록은 성공 후 날짜와 지역을 유지하고 주소, 사진, 긴급 여부를 초기화한다.
- 일괄등록은 1~10장의 사진을 각각 별도 업무 한 건으로 등록한다. 날짜, 지역, 긴급 여부를 공유하며 주소는 공란이다.
- 일괄등록의 성공 건은 유지하고 실패 사진만 재시도한다. 사진별 요청 키로 재시도 중복을 막는다.

## 목록과 권한

- 관리자, 공무, 팀장은 미완료·현장처리 건의 날짜, 지역, 주소, 긴급 여부를 목록에서 수정할 수 있다.
- 완료 건은 읽기 전용이고 팀장의 지역은 변경할 수 없다.
- 상세 화면은 목록의 명시적인 `상세/처리` 버튼으로 연다.
- `사진보기`는 현재 사용자가 조회할 수 있는 미완료·현장처리 건에서만 제공한다.
- 매니저는 담당 지역의 미완료(`registered`) 건만 목록·요약·상세·첨부 API에서 조회할 수 있다.
- 매니저가 현장처리를 등록하면 해당 건은 즉시 목록에서 사라진다.

## 상태와 사진 삭제

상태 전이는 `registered → field_processed → completed` 순서다. 현장처리 이력이 있는 건만 최종 완료할 수 있다. 완료 처리에서는 저장소의 모든 첨부 파일을 먼저 삭제하고, 성공한 경우에만 첨부 DB 레코드를 물리 삭제한 뒤 완료 상태를 확정한다. 삭제 실패 시 완료 처리를 중단한다.

## 검색과 통계

목록 검색은 지역, 주소, 매체, 현장 처리내용, 현장처리자를 대상으로 한다. 통계 상세와 CSV는 점검요청일, 지역, 주소, 이관사유, 긴급 여부, 현장처리자, 현장처리일시, 완료일시, 상태, 처리시간을 제공한다.
